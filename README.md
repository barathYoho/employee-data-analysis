# Employee Data Analysis

## Project Overview
This project focuses on analyzing employee data using Python and Pandas. The goal is to explore employee information and identify useful business insights.

## Dataset Details
- Dataset: employees.csv
- Total records: 8
- Total columns: 5
- Format: CSV

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Git and GitHub

## Initial Data Exploration
1. Load the employee dataset.
2. Check dataset shape.
3. Inspect dataset information using `info()`.
4. Generate statistical summaries using `describe()`.
5. Identify missing values using `isna().sum()`.
6. Identify duplicate records using `duplicated().sum()`.

## Business Questions
1. Which department has the highest number of employees?
2. Which city has the highest number of employees?
3. Which department has the highest average salary?
4. Who is the highest-paid employee?
5. What is the average salary of all employees?
